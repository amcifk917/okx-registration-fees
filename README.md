## 一般新手註冊後會落在哪個級別？

大多數剛註冊、資產量和交易量都不高的帳戶，會先按照普通用戶費率計算。這不代表註冊後要另外購買某個會員方案，也不代表需要先存入大額資金才能使用基本功能。

對新手來說，更值得先確認的是：

- 現貨交易和合約交易的費率是否相同
- 交易對是否屬於標準交易對或其他費率組別
- 充值、提幣和法幣買幣是否產生額外費用
- 使用市價單時會按照 Taker 費率計算
- 活動獎勵是否要求交易量、入金或完成身分驗證
- 產品是否在你的居住地開放

不要只看到某個頁面寫著「低手續費」就直接下單。實際成本還可能包含點差、資金費率、提幣網路費用、法幣支付費用和滑價。

## 為什麼 OKX 註冊收不到驗證碼？

收不到驗證碼時，可以按以下順序排查：

### Email 驗證碼沒有收到

先查看垃圾郵件、促銷分類和郵件過濾規則。若短時間內重複點擊發送，可能會造成舊驗證碼失效，這時應等待片刻後重新取得最新碼。

### 手機簡訊沒有收到

確認國家區號選擇正確，手機是否能正常接收其他簡訊，並檢查是否開啟了陌生號碼或國際簡訊封鎖。

### 顯示手機或 Email 已被使用

這通常表示該資料已經註冊過。官方建議先嘗試找回密碼，而不是重複建立帳戶。OKX 也提醒，一個身分證件通常只能綁定一個完成認證的帳戶。

### 邀請連結打不開

可以改用 OKX App，從註冊頁手動輸入 `CASH20`。但要留意，若改用其他入口後活動資訊沒有顯示，註冊前應先確認邀請碼是否已成功套用。

## OKX 註冊完成後，建議先做哪些設定？

完成 KYC 後，不要急著把所有資金轉入帳戶。可以先做幾項基本設定：

- 啟用雙重驗證，例如驗證器或安全金鑰
- 設定提幣白名單或反釣魚碼
- 確認登入裝置和安全通知
- 先小額測試充值與提幣流程
- 了解不同網路的提幣手續費
- 閱讀現貨、合約和槓桿產品的風險說明
- 在活動中心確認邀請獎勵是否需要額外任務

如果只是想買入並持有現貨，可以先熟悉現貨交易和提幣設定，不必一開始就使用合約或高槓桿。合約交易的損益變化速度更快，費用結構也不只包含單次買賣手續費。
